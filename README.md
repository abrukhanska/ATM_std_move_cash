# ATM_std

Проєкт банкомата на C++ командою std::move(cash).

## Структура

- src/domain/ — доменна логіка
- src/application/ — сервіси та прикладна логіка
- src/infrastructure/sql/ — робота з базою даних і SQL
- src/presentation/ — інтерфейс користувача
- 	ests/ — тести
- 	ests/support/ — допоміжні тестові компоненти
- docs/ — документація

CMakeLists.txt буде додано пізніше після узгодження структури.
